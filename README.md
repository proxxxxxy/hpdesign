# IROHA DESIGN — リデザイン

「余白と、暮らす。」を軸にした、イロハデザインのレスポンシブ建築サイトです。

## 起動

Node.jsで `npm run dev` を実行し、表示されるローカルURLを開きます。依存パッケージのインストールは不要です。公開用ファイルは `npm run build` で `dist/` に作成されます。構文確認は `npm run check`、動画制御の確認は `npm test` です。

## ファイル

- `index.html`：ページ、建築紹介、相談画面
- `styles.css`：PC・スマホのレイアウト、アニメーション
- `script.js`：スクロール連動、絞り込み、詳細表示、相談メモ
- `site.config.js`：動画と会社情報の設定
- `media-controller.js`：動画の遅延読み込み、再生・停止制御
- `assets/`：コンセプト画像、Web用動画3本、ポスター画像、支給ロゴ
- `VIDEO_PROMPTS.md`：Geminiに渡せる動画プロンプトと組み込み方法

元のClaudeのファイルは変更していません。新しいトップは `index.html` です。

## 主な動作

- 冒頭の外観映像とスクロールの速度差
- 画面への登場に合わせた文字・写真の表示
- 中盤の室内映像と工房紹介の空間映像
- 6件の架空の設計案のカテゴリ絞り込みと詳細ダイアログ
- 5段階の設計プロセスの開閉
- モバイルメニュー、キーボード操作、Escで閉じるダイアログ
- ページ全体の動きの停止・再開、OSの動きを減らす設定への対応
- サーバーへ送信しない相談メモの作成・コピー・保存

## 公開内容について

元の資料に含まれる6件の物件はサンプルです。本版では架空の設計案として明記しています。AI生成画像3点も実際の施工実績ではありません。実際の写真・図面を受領したら、画像・説明・ラベルを一緒に置き換えてください。4〜6件目の詳細画像は方向性を伝える参考画像として再利用しています。

所在地・代表者・資格登録番号・連絡先・サービスの条件は未確認です。未確認の事務所資格、所在地、竣工年、面積、顧客の声、無料相談・点検の約束は掲載していません。名称・業務・思想のコピーは既存デザインを元にした案であり、実際の事業内容に合わせて確認してください。

`site.config.js` の `address` と `contactEmail` は会社紹介へ反映します。`contactEmail` を設定すると、相談内容の確認後にメールアプリを開けます。フォームからの自動送信は行いません。`phone`・`representative`・`registration` は将来掲載用の予約項目で、現状は表示されません。

動きの停止はトップ右下のPAUSEボタンから行います。動画を含めて停止します。動画は画面に入ってから読み込み、画面外・非表示タブでは停止します。OSの動きを減らす設定や通信量節約設定では自動読み込みせず、再生ボタンから開始できます。自動再生できない場合や読み込み失敗時は静止画を表示します。外部読み込みはGoogle Fontsのみで、取得できない場合はシステムフォントを使用します。

## 素材とGitHubへの反映

支給素材の `1.mp4` はトップ、`2.mp4` は工房紹介、`3.mp4` は中盤の室内シーンへ採用しました。Web用MP4は1280×720・24fps、音声なし、読み込み開始を早めるfaststart設定で合計約5.4MBです。スマホでも映像全体が見える16:9の配置としています。Geminiの表示は元映像のままです。ロゴは支給画像の透明な余白のみを整え、ヘッダー・工房紹介・フッターとファビコンに反映しました。

`gemini動画一覧/` と `画像/` は元素材の保管場所としてGit管理対象外です。素材を追加しただけではアップロードせず、サイトを編集・確認した際に、完成版のコードと必要な `assets/` を `proxxxxxy/hpdesign` の `main` へ反映します。

このバージョンは本人限定プレビューとして公開します。一般公開の前に、会社情報と実際の事例へ置き換える運用を想定しています。
